### 第六步 · 奏请定夺

**默认呈卡片，不是纯 Markdown。** 纯文本奏折没有排版，图只是一串裸链接，
陛下看了没感觉——所以这一步要生成带排版的奏折卡片：
```
python scripts/imperial_kitchen.py memorial-scroll \
  --candidates <attach_photos 后的候选.json> --coupons <c.json> \
  --price <calculate-price 返回> --campaigns <官方活动> \
  --delivery <plan.json> --store <store.json> --out 御膳奏折.html
```
卡片结构（与 Markdown 奏折同源同据，只是有排版）：
抬头（日期·节气·主题·门店）→ 麦历（含三条边界）→ **御膳图鉴（两列网格，官方 CDN 原图）**
→ 礼部呈报（官方活动）→ 户部精算（券）→ 御膳账目（核价明细）
→ 拟旨下单（三重复述）→ **御前请旨（可点选项）** → 落款（臣绝不代付）。

纯文本版（`render`）仅在陛下要求"说人话/别整这些"或只需快速核对时使用。

结尾必须写明：**已查询、已核价、已推荐，但未下单、未付款**，请陛下自行前往麦当劳官方渠道购买。
并且**必须同时给出选项卡片**，不得只留一句"陛下可回复：…"。
