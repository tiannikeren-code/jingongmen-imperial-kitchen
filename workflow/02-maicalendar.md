### 第二步 · 麦历呈报（观象授时）
```
python scripts/imperial_kitchen.py date-context [--date YYYY-MM-DD]
python scripts/imperial_kitchen.py theme [--date YYYY-MM-DD]
```

**「麦历」是什么**：御膳房自编的**文化灵感栏目**——取当日二十四节气与传统节日为题，给今日膳食添一句由头。它**不是黄历**，三条边界必须写进输出：

| 边界 | 说法 |
|---|---|
| 不预测吉凶 | 不排宜忌、不算运势、不判好坏 |
| 不影响消费决策 | 今日吃什么只取决于陛下的预算、口味与官方价格，与节气无关 |
| 不冒充官方促销 | 非麦当劳官方活动；官方活动另见「礼部呈报」栏目 |

- 保留二十四节气（天文算法算交节时刻）与传统节日主题；**这就是全部的文化灵感来源**。
- 自动识别当前 Asia/Shanghai 日期、二十四节气、传统节日、法定节假日。
- 节气用天文算法（`ephem` 太阳视黄经）计算，已用权威分至点数据校验；节日用农历换算，已与国务院放假安排交叉验证。
- 数据缺失 → 自动降级为普通主题，**绝不编造节气**。
- 指定日期演示时必须标注「指定日期模拟」。
- 陛下说"不喜欢这个主题" → 加参数降级为"四时常态"（`opt_out`）。

如需展示麦当劳官方活动，**单独**调用：
```
mcp__mcd-mcp__campaign-calendar
```
并在输出里放进「礼部呈报」栏目，标明来自官方活动日历。
